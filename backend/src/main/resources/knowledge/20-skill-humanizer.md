# Skill：humanizer（Academic Style）

来源：https://github.com/blader/humanizer （MIT）。awesome-ai-research-writing Part II 列出本 skill。接到 Academic Style，不授予 AcademicSearch。

## 怎么做

先标模式再整段重写，不要逐词打补丁。保留数字、公式、Citation、术语。宁缺毋滥。

## 强信号（见到就可改）

- not X but Y / 不是…而是… 的假对比。
- 一段结束后的一句口号（That is the real win）。
- Let’s dive in / Here’s what you need to know 开场。
- 与空气抬杠（I’m not saying…）。
- 破折号（—）当万能连接。
- 空洞三点式。

## AI 高频词（空洞时才换）

delve, leverage, pivotal, tapestry, showcase, underscore, testament, vibrant, intricate, landscape（抽象）, foster, bolster。

## 学术场景额外约束

方法与结论用一般现在时。LaTeX 保留 cite/ref 与 $公式$，不要自己加粗。Word 输出禁止 Markdown。
已经自然的句子不要改。
