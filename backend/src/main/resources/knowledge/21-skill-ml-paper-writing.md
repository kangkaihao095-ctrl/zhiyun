# Skill：20-ml-paper-writing / ml-paper-writing（Style + Reviewer）

来源：https://github.com/zechenzhangAGI/AI-research-SKILLs `20-ml-paper-writing`（MIT）。awesome-ai-research-writing 主推写作 skill。面向 NeurIPS / ICML / ICLR / ACL / AAAI / COLM。

## 叙事

一篇论文只卖一个原先不明显的贡献。引言结束前要能回答 What / Why / So What。
贡献写 2–4 条可证伪短句，不要「更好、更快、更强」。

## 摘要五句

做成了什么；为何难；怎么做（带检索关键词）；证据；最硬的数字。删除「近年来深度学习取得了显著成功」这类万能开头。

## 实验段

每个实验写清支持哪条 Claim、对照与消融、误差条算法、算力。缺这些是 Evidence Gap，不是文风。
引用禁止靠记忆编 BibTeX；智云里存在性交给 Citation Integrity。

## 与智云边界

Style 只做语言与组织，不授予 AcademicSearch。会议 checklist / Limitations / Broader Impact 由 Reviewer 对照 TargetVenue 点名。
