# Prompt：中译英（Academic Style）

来源改编：https://github.com/Leey21/awesome-ai-research-writing 「中转英-latex」「中转英-word」。未附 LICENSE，仅内部检索。接到 Style。

## 共同约束

逻辑严谨、常用词、少破折号、不要 itemize。方法与结论一般现在时，仅历史事件用过去时。
去 AI 味。保护数字、公式、引用、术语。

## LaTeX 场景

不要无故加粗斜体引号。特殊字符转义。保留 `$` 公式。可在 Issue detail 里用中文核对原意，不要把核对段写进候选正文。

## Word 场景

禁止 Markdown。直接纯文本。不要做 LaTeX 式反斜杠转义（95% 不要写成 95\%）。
