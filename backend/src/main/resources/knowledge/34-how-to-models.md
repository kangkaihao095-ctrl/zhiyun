# 如何配置模型 / 模型配置怎么操作

检索关键词：模型配置怎么操作、模型配置这个咋操作、如何配置模型、怎么填 API Key、接通我的 API Key、BYOK、设置页模型。

论文审校的 7 个 Agent 可以换成用户自己的 OpenAI 兼容 Key；云笺和 RAG 检索仍走平台模型，不能换。Style（语言润色）不授予 AcademicSearch。没有给开发者的通用审校 API Key，也没有「联系商务做企业开放 API」这条产品线。

## 操作步骤

1. 打开左侧 **设置**。
2. 点 **模型配置**（路径 `/account?panel=models`）。
3. 点开某一个论文 Agent，选「接通我的 API Key」，再选提供商、填写 Base URL 与 API Key（以及模型 ID）。
4. 点 **保存**。也可以改回「使用平台默认」。

自备 Key 时 token 走你自己的云账单，平台只收技能与提示词服务费。额度在右上角；充值点右上角旁边的充值按钮，会弹出充值窗口。
