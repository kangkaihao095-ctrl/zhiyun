# 学术写作指南（Academic Writing / humanizer）

来源：智云 Academic Style Skill（humanizer + 20-ml-paper-writing），供 Style Agent 与客服 FAQ 检索。

## 应避免的 AI-like 句式

不要用 Firstly / Secondly / Moreover / Furthermore 起段。
不要用 “In conclusion, this paper has demonstrated the effectiveness of our approach.” 这类空泛收束。
不要用空洞三点式（“我们的贡献有三：更好、更快、更强”）却不给出可核对的操作定义。
不要循环同义改写同一句话。

## 应保留的事实

润色时不得改：数字、公式、Citation、DOI、实验结果、消融设置、超参、技术术语、方法步骤、作者原始结论。
页数、DPI、纸张尺寸是格式事实，不是文风问题。

## 结构建议

Introduction 先给可检验贡献，再定位相关工作缺口。
Method 使读者能复述算法，而不是形容词堆叠。
Experiments 每个优越性声明附近应有对照、消融或误差来源；否则是 Evidence Gap，不是文风问题。
Conclusion 只总结已展示的证据，不发明未做实验。

## 与 Citation 的边界

Style Agent 不检索文献、不授予 AcademicSearchTool。引用对错交给 Citation Integrity。
英语润色、中文润色、中译英见 25–27；LaTeX 格式卫生见 12 与 28。TargetVenue 有值时按该刊文风/时态，不要用错模板套话。
