# Skill：doc-coauthoring（Planning / Execution 检索）

来源摘录：https://github.com/anthropics/skills `doc-coauthoring`（Apache 2.0 示例 skill）。awesome 仓库列为写作协作 skill。

## 三阶段

1. 收集读者、贡献、不确定点（澄清，不改稿）。
2. 按节起草，一次一节。
3. 读者测试：找出不清或易误解处。
