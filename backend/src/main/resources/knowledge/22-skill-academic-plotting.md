# Skill：academic-plotting（Figure / PDF）

来源：https://github.com/zechenzhangAGI/AI-research-SKILLs `20-ml-paper-writing/academic-plotting`（MIT）。

## 选图

有数值轴用折线/柱/散点/热力；盒子加箭头才是架构图。对比方法 × 基准用分组柱；时间轴用折线；矩阵用热力。少用饼图。

## 规范

矢量 PDF/EPS；照片 ≥300 dpi。图内不要标题（caption 承担）。色盲友好，线型与颜色一起用。
「我们的方法」用固定强调色。图注须能脱离正文读懂。

## 智云边界

审校主链不负责生成架构图。已有图：白底、短英文标签、不要长句。Caption 句式见 09-figures-pdf。DPI/页尺寸由程序查。
